OPEN MOOC · HTML5 무크 강의자료 센터
=================================

구성
- index.html   : 반응형 무크센터 홈페이지 (CSS / JavaScript 포함)
- courses.json : 강좌 및 강의자료 데이터 파일
- mobile-webapp-design.html : 첫 번째 강좌의 연결 확인용 샘플 페이지
- android-ios-design.html   : 두 번째 강좌의 연결 확인용 샘플 페이지

1. 실행
  index.html을 Chrome에서 열면 초기 강좌가 표시됩니다.
  인터넷 연결 없이도 기본 강좌 목록을 볼 수 있습니다.
  로컬 파일 모드에서는 초기 강좌 데이터가 HTML에 내장된 데이터를 사용하며,
  GitHub Pages 등 웹서버로 배포하면 courses.json을 불러옵니다.

2. 강의자료 연결
  초기 링크 mobile-webapp-design.html 및 android-ios-design.html은 예시 파일명입니다.
  압축파일에 있는 두 예시 HTML은 연결 확인용 샘플 페이지입니다.
  실제 같은 이름의 자료 파일로 교체하거나,
  '콘텐츠 관리' > '강좌 상세' > '수정'을 통해 실제 https://... URL로 교체하세요.

3. 새로운 강좌 추가
  '콘텐츠 관리' > '+ 새 강좌 등록' 클릭
  강좌명과 분류 입력 > 저장 > '자료 추가' 클릭 > 자료명/URL 입력

4. 기존 강좌에 자료 추가
  '콘텐츠 관리' 클릭 > 해당 강좌의 '자료 보기' 클릭 > '+ 자료 추가'
  1개 강좌에 여러 주차의 강의안·영상·실습 링크를 등록할 수 있습니다.

5. 여러 학생에게 수정 사항 공개하기 (중요)
  '콘텐츠 관리'로 입력한 변경 사항은 **현재 브라우저 localStorage에만** 저장되므로,
  다른 학생에게 즉시 공유되지 않습니다.
  관리 도구의 'courses.json 다운로드'를 실행해 파일을 저장한 다음,
  GitHub Pages, 학교 웹서버 등에서 기존 courses.json 파일을 교체해야
  다른 학생들의 브라우저에도 새로운 자료가 반영됩니다.
  강좌 HTML 파일을 수정할 필요는 없습니다.

6. JSON 파일 직접 편집
  courses.json의 courses 목록에 강좌 객체를 추가하거나,
  기존 강좌 materials 목록에 강의자료 객체를 추가할 수 있습니다.
  id는 강좌와 자료 각각 서로 다른 문자열로 지정하세요.
  url은 https://... 주소 또는 같은 폴더에 있는 상대 파일 경로를 사용합니다.

7. 주의
  이 템플릿은 HTML/CSS/JS로 동작하는 정적 학습자료 포털입니다.
  사용자 로그인, 수강 등록, 학습 진도 저장, 실제 서버 관리자 권한 등은 지원하지 않습니다.
  '콘텐츠 관리'는 로그인/암호 기능이 아니며, 방문자 누구나 자기 브라우저에서만
  데이터를 편집할 수 있습니다. 이를 중앙 서버에 반영하려면 JSON 파일을 배포해야 합니다.
